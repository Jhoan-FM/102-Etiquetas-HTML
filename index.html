102 Etiquetas HTML

Aprende con Jhoan Figuereo

<input type="number">

Descripción: Define un campo de entrada que permite a los usuarios introducir solo números. Puedes especificar un rango de valores.

Ejemplo: <input type="number" min="1" max="10">

<p> - Define un párrafo de texto

Descripción: Se utiliza para estructurar el contenido en párrafos.

Ejemplo de uso:

<p>Este es un párrafo de texto.</p>

Comentario: Cada vez que utilices la etiqueta <p>, el navegador agregará un pequeño espacio entre los párrafos por defecto.

<img> - Incrusta una imagen

Descripción: Se usa para insertar imágenes en la página web.

Ejemplo de uso:

<img src="IA.jpg" alt="Descripción de la imagen">

Comentario: El atributo src especifica la ubicación de la imagen, mientras que alt proporciona un texto alternativo en caso de que la imagen no se cargue.

<div> - Define una sección o contenedor

Descripción: Se usa para agrupar otros elementos HTML y aplicarles estilos o manipulaciones.

Ejemplo de uso:

<div class="contenedor">Contenido aquí</div>

Comentario: La etiqueta <div> es muy útil para estructurar el diseño de la página utilizando CSS.

<h1> - Define el encabezado más importante

Descripción: Se utiliza para definir los encabezados de mayor jerarquía (generalmente el título de una página).

Ejemplo de uso:

<h1>Este es un título principal</h1>

Comentario: Existen otras etiquetas de encabezado como <h2>, <h3>, etc., que tienen una jerarquía menor.
